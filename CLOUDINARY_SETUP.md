# Настройка Cloudinary для хранения изображений

## Зачем это нужно?

Render использует эфемерную файловую систему - все загруженные файлы удаляются при перезапуске сервера. Cloudinary - это облачное хранилище для изображений, которое решает эту проблему.

## Шаг 1: Регистрация в Cloudinary

1. Перейдите на https://cloudinary.com/
2. Нажмите **Sign Up for Free**
3. Заполните форму регистрации
4. Подтвердите email

**Бесплатный план включает:**
- 25 ГБ хранилища
- 25 ГБ трафика в месяц
- Более чем достаточно для учебного проекта!

## Шаг 2: Получение учетных данных

После входа в аккаунт:

1. Перейдите в **Dashboard** (главная страница)
2. Найдите раздел **Account Details**
3. Скопируйте три значения:
   - **Cloud Name** (например: `dxxxxxxxxxxxxxx`)
   - **API Key** (например: `123456789012345`)
   - **API Secret** (нажмите на глаз чтобы показать, например: `AbCdEfGhIjKlMnOpQrStUvWx`)

## Шаг 3: Добавление в Render

1. Зайдите в панель управления Render
2. Откройте ваш сервис **real-estate-objects-base**
3. Перейдите на вкладку **Environment**
4. Нажмите **Add Environment Variable**
5. Добавьте три переменные:

```
CLOUDINARY_CLOUD_NAME = ваш_cloud_name
CLOUDINARY_API_KEY = ваш_api_key
CLOUDINARY_API_SECRET = ваш_api_secret
```

6. Нажмите **Save Changes**
7. Render автоматически перезапустит сервис

## Шаг 4: Локальная разработка (опционально)

Если разрабатываете локально, добавьте в `.env` файл:

```bash
# .env файл в корне проекта
CLOUDINARY_CLOUD_NAME=ваш_cloud_name
CLOUDINARY_API_KEY=ваш_api_key
CLOUDINARY_API_SECRET=ваш_api_secret
```

**⚠️ Не коммитьте `.env` файл в git!**

## Шаг 5: Проверка работы

После настройки:

1. Зайдите на ваш сайт: https://real-estate-objects-base.onrender.com
2. Войдите под своим аккаунтом
3. Перейдите в **Мои объекты**
4. Создайте новый объект и загрузите фото
5. Фото должно успешно загрузиться
6. Проверьте что фото отображается
7. Откройте сайт с другого компьютера - фото должно быть видно!

## Проверка статуса

Вы можете проверить используется ли Cloudinary:

```bash
curl https://real-estate-objects-base.onrender.com/api/upload/config
```

Ответ должен быть:
```json
{
  "storage_type": "cloudinary",
  "max_file_size_mb": 5,
  "allowed_extensions": [".jpg", ".jpeg", ".png", ".gif", ".webp"]
}
```

Если `storage_type: "local"` - Cloudinary не настроена, проверьте переменные окружения.

## Управление изображениями в Cloudinary

После загрузки изображений:

1. Зайдите в **Media Library** в Cloudinary dashboard
2. Откройте папку **real_estate_app**
3. Здесь будут все загруженные изображения
4. Можно просматривать, скачивать, удалять

## Автоматическая оптимизация

Приложение автоматически:
- Ограничивает размер до 1200x900px
- Оптимизирует качество
- Конвертирует в оптимальный формат (WebP если браузер поддерживает)

## Fallback режим

Если Cloudinary не настроена:
- Система автоматически переключится на локальное хранилище
- Изображения будут работать локально
- Но на продакшне (Render) они пропадут после перезапуска

## Дополнительные возможности (опционально)

Cloudinary предлагает:
- Трансформации изображений на лету
- Автоматическую оптимизацию
- CDN для быстрой загрузки по всему миру
- Видео хранилище
- AI-теги и распознавание лиц

Документация: https://cloudinary.com/documentation

## Поддержка

Если возникли проблемы:
1. Проверьте правильность переменных окружения
2. Убедитесь что скопировали все три значения
3. Проверьте что не добавили лишние пробелы
4. Перезапустите сервис в Render вручную (Manual Deploy → Clear build cache & deploy)
